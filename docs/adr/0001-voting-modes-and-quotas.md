# 자유 투표와 참여자별 투표권 할당을 함께 지원한다

합주방은 생성 시 **자유 투표** 또는 **투표권 할당**을 선택한다. 기존 합주방은 모두 자유 투표로 유지하며, 할당 모드는 방 생성 시 1~99개의 기본 투표권을 정하고 참여자별로 0~99개까지 조정한다. 찬성·반대 모두 한 표를 사용하고, 방향 변경은 추가 사용 없이 기존 한 표를 유지하며, 취소하면 한 표가 반환된다.

투표가 한 표라도 존재하면 모드 변경을 막는다. 투표가 없을 때 할당 모드로 전환하면 새 기본값을 현재 참여자 전원에게 적용한다. 기본값을 나중에 바꾸는 경우에는 미래 참여자에게만 적용하고, 기존 참여자 일괄 변경은 별도 명시적 동작으로 제공한다. 이미 사용한 표보다 낮게 할당량을 줄이는 변경은 기존 투표를 임의 삭제하지 않고 거부한다.

## Consequences

- 방장도 일반 참여자와 같은 투표권 제한을 받는다.
- 투표권 초과 방지는 화면이 아니라 동시 요청에도 안전한 DB 연산에서 보장해야 한다.
- 일반 참여자는 본인 현황만 보고, 방장은 톱니바퀴 설정에서 전체 할당·사용 현황을 관리한다.
