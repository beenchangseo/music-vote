# 신규 합주방은 카카오 로그인 참여자만 받는다

합주방을 만들려면 카카오 로그인이 필요하고, `creator_user_id`가 있는 합주방에서는 투표·후보곡 추가·셋리스트 편집도 모두 로그인 참여자만 수행한다. 안정적인 계정 식별자가 있어야 투표권 할당, 참여자별 사용량, 등록자 기준 삭제 권한, 중복 투표 직렬화를 서버에서 보장할 수 있기 때문이다. 닉네임은 카카오 프로필에서 자동으로 가져오므로 참여자가 따로 입력하지 않는다.

`creator_user_id`가 비어 있는 기존 합주방은 새로 만들 수 없다. [ADR 0012](./0012-archive-pre-login-playlists.md)에서 이 합주방들을 읽기 전용 보관 상태로 바꾸면서 닉네임 기반 익명 흐름을 제거했다.

## Consequences

- 단톡방 링크를 처음 여는 멤버는 투표 전에 카카오 로그인 한 단계를 거친다. 가입 마찰 0이라는 초기 약속은 "카카오 로그인 1회"로 바뀌었고, 홍보 카피와 문서도 이 기준을 따른다.
- 익명 경로와 로그인 경로가 `castVote`, 방장 판정, RLS 정책에 이중으로 남아 있었다. ADR 0012에서 익명 경로를 제거해 하나로 합쳤다.
- 방장 판정은 `creator_user_id` 매칭으로 한다. `adminToken`은 보관 합주방의 삭제에만 쓴다.
