# 투표권 할당 모드에서는 한 후보곡에 여러 표를 줄 수 있다

투표권 할당 모드의 투표권은 후보곡 수가 아니라 실제 투표 횟수를 제한한다. 참여자는 같은 후보곡의 같은 방향 화살표를 반복해서 눌러 여러 표를 줄 수 있고, 각 표는 투표권을 하나씩 사용한다.

한 참여자는 한 후보곡에 찬성과 반대를 동시에 보유하지 않는다. 기존 방향과 반대되는 화살표를 누르면 기존 표를 한 개씩 취소하고 투표권을 반환한다. 기존 표가 0개가 된 뒤 다시 누르면 그 방향의 새 표가 추가된다.

자유 투표는 투표권 제한이 없으므로 반복 투표를 허용하지 않고 기존 후보곡당 1표 토글 동작을 유지한다.

## Consequences

- 투표 점수는 투표 행의 합계이며, 같은 참여자의 닉네임이 여러 표에 나타날 수 있다.
- 기명 화면에서는 같은 닉네임을 반복 나열하지 않고 방향별 표 수로 묶어서 보여준다.
- 할당 모드의 사용량은 서로 다른 후보곡 수가 아니라 유지 중인 전체 투표 행 수다.
- 사용자·후보곡 조합의 유일 제약을 제거하되 사용자별 투표 처리와 투표권 검사는 DB에서 직렬화한다.
