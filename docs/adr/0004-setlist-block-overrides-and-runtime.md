# 셋리스트 곡 블록은 원본을 보존하고 수정값만 덮어쓴다

곡 블록의 제목과 연주 시간 수정은 후보곡 원본을 변경하지 않고 셋리스트 항목에 선택적 수정값으로 저장한다. 초기화는 수정값을 지워 원본 제목과 시간으로 돌아간다. YouTube 시간 자동 조회는 현재 oEmbed 기반 흐름에 추가하지 않고 추후 개선으로 남긴다.

인터벌 블록은 이름(최대 50자), 설명(최대 200자), 0 이상의 정수 분과 0~59의 정수 초를 가진다. 셋리스트 화면에서는 이름 1줄·설명 2줄로 접고 사용자가 펼친 상태는 현재 화면을 보는 동안만 유지한다. PDF에는 전체 항목과 설명을 여러 페이지로 표시하고, 한 장짜리 공유 이미지는 공간에 들어가는 항목까지 전체 설명을 표시한 뒤 나머지를 `외 N개 항목`으로 안내한다.

토탈 시간은 셋리스트 전용 시간이 있으면 우선 사용하고, 없으면 후보곡 원본 시간을 사용하며, 모든 인터벌 시간을 더한다. 시간이 없는 곡은 합계에서 제외하되 `N곡 시간 미입력`으로 명시한다. 상단 개수는 인터벌을 제외한 곡 블록만 세어 `N곡`으로 표시한다.
