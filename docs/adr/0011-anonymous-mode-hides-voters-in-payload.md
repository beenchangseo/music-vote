# 익명 모드는 화면이 아니라 페이로드에서 투표자를 가린다

익명 모드의 합주방은 투표자 닉네임과 계정 식별자를 클라이언트로 내려보내지 않는다. 종전에는 서버가 모든 투표 행을 그대로 보내고 `VoterStrip`이 화면에서만 감췄기 때문에, 개발자 도구로 페이로드를 열면 누가 어느 곡에 무엇을 찍었는지 그대로 보였다. 익명이 기본값인 제품에서 화면 가림은 익명이 아니다.

기명 모드로 바꾸면 그때부터 닉네임과 표 방향을 내려보낸다. 계정 식별자는 어느 모드에서도 내려보내지 않는다.

계정이 없는 기존 익명 합주방은 예외다. 내 표를 닉네임으로만 구분할 수 있어 종전대로 닉네임을 내려보낸다. 이 합주방들은 새로 만들 수 없고, [ADR 0009](./0009-login-required-for-new-rooms.md)의 legacy 정리 대상이다.

## Consequences

- 로그인 합주방에서 내 표는 서버가 계정 기준으로 계산해 내려보낸다. 클라이언트는 더 이상 투표 행에서 내 표를 찾지 않는다.
- 실시간 갱신도 같은 제약을 받는다. `votes` 변경을 그대로 흘리는 구독 대신 [ADR 0010](./0010-realtime-by-broadcast-notification.md)의 내용 없는 알림을 쓴다.
- `votes` 테이블 자체는 아직 SELECT가 공개다. 공개 anon 키로 PostgREST를 직접 호출하면 익명 합주방의 투표자를 여전히 조회할 수 있다. 앱 페이로드만 막은 상태이며, 테이블 권한을 좁히는 작업은 남아 있다.
