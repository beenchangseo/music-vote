# 다른 버전은 댓글과 분리된 YouTube 링크 목록으로 관리한다

후보곡의 **다른 버전**은 YouTube 링크, 자동 조회한 영상 정보, 선택형 100자 설명, 등록자를 별도 데이터로 저장한다. 곡 카드에는 댓글과 별개의 아이콘과 개수를 표시하고, 댓글과 유사한 모바일 모달에서 추가·수정·삭제한다.

원본 영상이나 이미 등록된 영상과 중복돼도 차단하지 않는다. 대신 `그래도 추가하시겠습니까?` 또는 `그래도 변경하시겠습니까?` 확인을 거친다. 로그인 합주방에서는 등록자와 방장이 수정·삭제할 수 있고, 닉네임으로 본인을 증명할 수 없는 옛 익명 합주방에서는 방장만 수정·삭제할 수 있다.
