# 투표권·다른 버전·셋리스트 편집 구현 계획

기준 문서: `CONTEXT.md`, `docs/adr/0001`~`0007`.

## 완료 조건

- 기존 합주방은 자유 투표와 모두 편집 가능한 셋리스트 동작을 유지한다.
- 신규 합주방은 자유 투표 또는 기본 투표권이 있는 할당 모드로 생성된다.
- 참여자는 첫 방문에 자동 등록되고, 투표권 초과가 동시 요청에서도 서버에서 차단된다.
- 방장은 톱니바퀴 설정에서 모드·기본값·개별값을 관리한다.
- 후보곡 등록자와 방장은 합의된 범위에서 곡과 다른 버전을 수정·삭제한다.
- 셋리스트 권한 토글이 모든 구조 편집에 UI와 서버 양쪽에서 적용된다.
- 인터벌과 곡 블록을 수정·초기화할 수 있고 토탈 시간이 합의된 기준으로 표시된다.
- 캘린더·포스터 코드와 포스터 데이터가 완전히 제거된다.
- 타입 검사와 lint가 통과하고 핵심 정책을 자동 검증한다.

## 1. 데이터 마이그레이션

`supabase-migration-v10.sql`을 멱등형으로 추가한다.

- `playlists`
  - `voting_mode`: `free | allocated`, 기본 `free`
  - `default_vote_limit`: 1~99, 기본 3
  - `setlist_edit_mode`: `everyone | host_only`, 기본 `everyone`
- `playlist_members`
  - `vote_limit`: 0~99
- `setlist_items`
  - `description`
  - `title_override`
  - `duration_override_seconds`
- `song_versions` 신규 테이블
  - 곡 FK, URL, 영상 ID, 제목, 썸네일, 설명, 등록자 ID·닉네임, 생성·수정 시각
- 투표 모드 전환·할당 변경·투표 cast를 원자적으로 처리하는 Postgres 함수 추가
- 셋리스트 변경 정책을 편집 모드와 방장·참여자 여부에 맞게 재작성
- 포스터 객체 정리 후 `poster_url` 제거를 위한 운영 절차와 SQL 포함

## 2. 공통 도메인·권한 계층

- `src/lib/types.ts`에 새 모드, 참여자, 다른 버전, 셋리스트 수정 필드를 추가한다.
- 방장 또는 등록자 판정을 서버 공통 함수로 분리한다.
- 셋리스트 편집 가능 여부를 서버 공통 함수로 분리한다.
- 투표권 표시·합계 계산과 셋리스트 유효 제목·시간 계산을 순수 함수로 분리해 테스트한다.

## 3. 합주방 생성과 참여자 등록

- 생성 폼에 투표 모드 선택을 추가한다.
- 할당 모드 선택 시 기본 투표권 입력을 노출한다.
- `createPlaylist`가 방장을 참여자로 함께 등록한다.
- 로그인 사용자가 합주방을 처음 열면 `playlist_members`를 upsert하고 현재 기본값을 복사한다.

## 4. 투표 설정과 투표 처리

- 방장 전용 톱니바퀴 버튼과 모바일 모달을 추가한다.
- 투표가 0표일 때만 모드를 변경한다.
- 기본값 변경은 미래 참여자에게만 적용하고, 명시적 전체 적용 동작을 별도로 제공한다.
- 개별·일괄 변경은 현재 사용량보다 작으면 대상자를 알려주고 거부한다.
- 참여자에게 본인의 사용/할당/남은 표만 표시한다.
- `castVote`는 DB 함수로 위임해 할당 초과와 동시 요청을 방지한다.

## 5. 곡 삭제와 다른 버전

- `SongCard`의 관리자 토큰 조기 종료를 제거한다.
- `removeSong`에서 로그인 방장 또는 곡 등록자를 검사하고, 익명 합주방은 방장 토큰만 허용한다.
- `song-version.ts` Server Action과 `SongVersionModal`을 추가한다.
- 곡 페이지의 최초 조회에 버전 개수를 포함하고 모달 내용은 필요할 때 조회한다.
- 중복은 서버가 유형을 반환하고, 사용자의 명시적 확인 후 `force` 요청으로 저장한다.

## 6. 셋리스트 편집

- 방장 전용 셋리스트 편집 토글을 추가한다.
- 모든 셋리스트 변경 Action에서 동일한 권한을 검사한다.
- 인터벌 생성 폼에 설명을 추가하고 수정에도 같은 폼을 재사용한다.
- 곡 블록 편집 모달에 셋리스트 전용 제목·시간과 초기화를 제공한다.
- 인터벌 접기/펼치기를 로컬 UI 상태로 관리한다.
- 상단을 `N곡 · 토탈 시간 · N곡 시간 미입력`으로 고친다.
- 공유 이미지와 인쇄가 설명과 수정값을 사용하도록 갱신한다.

## 7. 캘린더·포스터 제거

- `SetlistCalendarButton`, ICS Route, 관련 EventMap·문서를 제거한다.
- `PosterUploadButton`, `PosterPolaroid`, 포스터 Action·props·OG 합성을 제거한다.
- Storage 객체 수를 기록하고 모두 삭제한 뒤 0건을 확인한다.
- 버킷과 `poster_url` 컬럼을 제거한다.

## 8. 검증

- 곡 삭제: 방장, 등록자, 다른 참여자, 익명 방장을 각각 검증한다.
- 투표: 자유 모드, 할당 사용·방향 전환·취소·초과·동시 요청을 검증한다.
- 설정: 투표 존재 시 모드 변경 거부, 사용량 미만 할당 거부를 검증한다.
- 다른 버전: YouTube 검증, 중복 확인, 등록자·방장 권한을 검증한다.
- 셋리스트: 모두/방장 전용 모드의 추가·수정·초기화·순서·삭제를 검증한다.
- 토탈 시간: 수정값 우선, 원본 fallback, 인터벌 합산, 미입력 개수를 검증한다.
- `npx tsc --noEmit`, `npm run lint`를 실행한다.
- Next 16.2.1의 알려진 로컬 빌드 회귀 외 신규 빌드 오류가 없는지 확인한다.
